# 自动运行

> 所有人决定（2026-09-28）：在本机用 Windows 任务计划程序自动运行；工作日开盘前跑完整流程，周末只跑结算和加密货币影子。

## 时间安排

| 任务 | 时间 | 内容 |
|---|---|---|
| Daily | 周一至周五 **纽约 08:45**（美股开盘前 45 分钟，8:30 宏观数据公布之后） | `app.py --mode daily`：结算 → 新闻 → 影子与临时影子 → 证据层 → 主管线 → missed_path → 持仓巡检 → 晋升评审 → 警报 |
| Weekend | 周六、周日 12:00（本地） | `app.py --mode weekend`：结算 + 加密货币影子（chain_oracle、defi_scout） |
| Dashboard | 登录时 | 仪表盘 http://127.0.0.1:8520 |

**为什么在开盘前**：决策用前一天的完整收盘数据和一夜的新闻，并在当天开盘成交（账本规则是"决策之后的下一个开盘"），所有人收到警报也能在开盘时照着执行。港股、日股、欧股在这个时间要么已收盘、要么在盘中，按同一规则在各自下一个开盘成交，不会用到未来数据。

**为什么周末只跑加密货币**：其他市场休市，周末决策只能用周五的数据、等周一开盘成交，不如周一开盘前再做；加密货币 7×24 交易，周末也要结算和决策。

**美国夏令时**：纽约 08:45 在美国夏令时期间是 12:45 UTC，冬令时是 13:45 UTC。任务每天在这两个时刻各触发一次（利雅得 15:45 / 16:45，北京 20:45 / 21:45），由 `scheduled_run.py` 按纽约时间判断：早于纽约 08:25 不跑；同一天只成功跑一次。换时区后重新运行安装脚本即可。

**美股节假日**：没有接节假日日历，节假日照常运行，决策顺延到下一个开盘日成交；结果不受影响，只多花一次 token。

## 安装与卸载

```powershell
powershell -ExecutionPolicy Bypass -File marketmind\scripts\install_schedule.ps1
powershell -ExecutionPolicy Bypass -File marketmind\scripts\uninstall_schedule.ps1
```

- 任务在任务计划程序的 `\MarketMind\` 文件夹下，只在所有人登录时运行（不保存密码）；电脑睡眠时会被唤醒（需要电源选项里"允许唤醒定时器"为启用）；错过的触发会在开机或唤醒后补跑。
- 手动检查某次触发会不会运行：`python marketmind/scripts/scheduled_run.py --slot weekday --dry-run`。

## 运行保障

- **每天一次**：状态记在 `data/scheduler/state.json`；成功后当天其他触发一律跳过；失败的可由当天下一次触发重试一次。
- **防重入**：`data/scheduler/run.lock`（记录进程号，3 小时后视为失效）。
- **超时**：完整流程 60 分钟、周末 30 分钟，超时强制结束并记为失败。
- **日志**：`data/logs/scheduled/<纽约日期>-<时段>.log`。
- **失败通知**：通过已配置的推送渠道（见 `docs/S8_DESIGN.md`）发送，内容已脱敏；没配渠道时只记录。仪表盘"系统健康"页显示最近的自动运行记录。
