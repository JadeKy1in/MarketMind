# 月度长周期趋势规则回测（2026-09-29）

> 纯代码生成（`python -m marketmind.trend.monthly_report`），所有数字由 `marketmind/trend/` 从缓存行情计算（SPEC L3）。规则、参数与通过标准在看结果之前登记在 `docs/TREND_DESIGN.md` §10（单独一次提交）。**只回测，未接入每日运行或警报。**

## 给所有人的摘要

- **结论：两条月度规则都没有通过事先定的标准，不建议按现在的形式采用。** M1（10 个月均线）未过：在场时间 ≤ 60%；最大回撤 ≤ 等权持有的一半。M2（12 个月动量）未过：在场时间 ≤ 60%；最大回撤 ≤ 等权持有的一半；CAGR ≥ 等权持有 − 3 点。事先登记的 12 组相邻参数里 0 组通过。
- **做到了的**：警报很少——6 个标的合计每年入场 M1 4.7 次、M2 3.2 次（日线版同样 6 个标的 12.7 次，全池 28 标的 66.2 个）。大行情吃得更多：同样 116 段大行情里，行情走到一半时在场的比例 M1 58%、M2 72%（日线版 43%），平均吃到整段涨幅的 66% / 74%（日线版 30%）。
- **没做到的 1：不是"大部分时间持币"**。每个标的平均有 69%（M1）/ 70%（M2）的时间在场，超过 60% 的上限；组合平均投入 64% / 68%。月度规则的本质是"大部分时间跟着趋势持有，只躲开大熊市"。
- **没做到的 2：会被套**。组合最大回撤 M1 -71.0%、M2 -65.2%，等权买入持有 -74.2%；最差年 M1 2018 -52.2%、M2 2018 -49.6%。原因是加密：月度检查离场太慢，ETH 单独按 M1 做的最大回撤 -94.2%（持有 -94.0%），BTC -73.4%（持有 -83.8%）；而且持有期间不再平衡，涨上去的加密占了组合的大头。
- **收益**：CAGR M1 24.0%、M2 16.3%，等权买入持有 22.4%，SPY 买入持有 11.1%。高数字主要来自少数几年的加密暴涨（M1 2017 年 1238%），前半段（2006-2015，还没有加密）M1 只有 5.0%、M2 5.9%，不能当作以后的预期。
- **事后诊断（不参与判定）**：只看 4 个 ETF（SPY/QQQ/GLD/TLT，每个 1/4）时，M1 最大回撤 -13.1% vs 等权持有 -28.6%，CAGR 8.1% vs 11.6%，在场时间 71%。也就是说，月度均线在传统资产上"降回撤"有效（与 Faber 的结论一致），但在加密上保护不够，且在场时间始终偏高。
- **建议**：不接入。如果还想要"少警报 + 吃中段"，下一步可以事先登记一个组合方案再回测（例如 ETF 用月度规则、加密用更快的离场或更小的仓位上限），本次不做。
- **注意**：不含税；加密从 2016/2017 年才有足够月线；2017 年加密的百倍行情对组合数字影响极大；缓存为 2026-09-29 重新抓取。

- 标的：SPY, QQQ, GLD, TLT, BTC-USD, ETH-USD；6 个等权名额，入场时买当时总权益的 1/6，持有期间不再平衡，离场全部卖出；没有足够历史的名额留作现金。

- 组合区间 2006-01-03 至 2026-09-28（20.7 年）；现金 0 息（主口径）；前后两半以 2016-01-01 分界。门槛：^IRX 252-day mean (yfinance)。

- 日线版对照 = `TREND_DESIGN.md` §3 的主设计（55 日突破 + SMA200 + 12 个月动量，吊灯止损），同一份缓存重新计算；"日线版 6 标的"用同样 1/6 名额，"全池 28 标的"用原报告的每笔风险 1% 仓位。

## 9. 结论与建议

1. **按事先标准**：M1 未通过（未过：在场时间 ≤ 60%；最大回撤 ≤ 等权持有的一半）；M2 未通过（未过：在场时间 ≤ 60%；最大回撤 ≤ 等权持有的一半；CAGR ≥ 等权持有 − 3 点）。未通过的不采用，也不接入每日运行。
2. **月度规则满足了"少警报"和"吃中段"**：每年 3.2-4.7 次入场，大行情中段在场 58%-72%，日线版 43%。
3. **但它与"大部分时间持币、不被套"相矛盾**：长周期规则天然大部分时间在场，离场要等月线跌破均线或 12 个月收益转负；对一个月能跌 30%-50% 的加密，离场时往往已从高点回吐一半以上。
4. **下一步（未做，需所有人决定、另行预先登记）**：例如"ETF 用月度规则 + 加密用日线吊灯止损离场"，或给加密单独设较小的仓位上限并定期削减；也可以接受"在场约七成"的画像，只把月度规则当作传统资产的风险开关。
5. **注意事项**：回测不含税；加密早期（2016-2017）的百倍行情主导了组合收益，未来不可重复；yfinance 复权价含分红；月度规则两次检查之间没有止损，单月暴跌风险完全暴露。
