# 退出结构回放与基线对照（2026-10-02，只读分析）

> 所有人 2026-10-02 选定：先只出分析，不改交易规则。外网调研怀疑"止损太近、目标太远"（止损中位 3.2%、目标 5.5%、持有 12 天）是亏损主因，本分析用账本实测检验。

## 结论

- **退出结构不是主因。** 换成任何止损 / 目标 / 只到期规则，均值差都在 ±0.12 个百分点以内，与 0 无法区分。收紧止损（1.5 / 2·ATR）一致更差；放宽止损（3·ATR、原距离 ×2）约等于只到期。证伪退出有用：被证伪的 9 笔若持有到今天是 −2.35%，实际 −2.05%。
- **亏损主要来自两处：**
  - 偏多遇跌：LLM 做多占 68%，同期 SPY −0.52%；空单 +0.41%，多单 −0.98%。
  - 加密货币成本：12 笔往返成本约 2.3%，毛收益 −0.04%、净收益 −2.34%，单独拖累全样本约 0.19 个百分点。剔除加密后为 −0.37%（ETF +0.23%，个股 −0.97%）。
- **简单基线这一轮不差于 LLM：** 20 日动量 +0.02%，趋势状态机 −0.06%，LLM 方向（只到期）−0.50%，在 5000 次随机方向中排第 10 百分位。
- **样本极小：** 只有 4 个入场日，持有中位 1 天；按入场日聚类的 bootstrap 只有 3–4 个簇，区间不可靠。以上都只是苗头。

## 样本与方法

- 已开仓记录 210 条：LLM 选出的 144 条（shadow 121、watch_counterfactual 11、temp_shadow 8、main 2、main_forced 1、playground 1），另有 benchmark 随机对照 66 条，单独统计。
- 回放调用项目自己的 `settlement.simulate`，只改止损 / 目标 / 证伪价位，方向、入场、持有期不变，成本模型与账本相同。49 条已结算中 47 条（96%）与账本一致；不一致的 2 条都是期货（SI=F、PL=F）的跳空止损。
- 126 个标的全部取到日线；PL=F 有 188 根、SI=F 有 7 根只有收盘价的 K 线，按项目规则只看收盘。
- 未结算记录按最新收盘价计浮动盈亏；"只到期"一栏 93% 是浮动结果。
- ATR 止损的参考价用决策时的快照价，没有则用前收。超额收益统一对 SPY（账本对加密用 BTC）。趋势状态在入场前一天可算，门槛用 4% 年化常数（假设值，未取 ^IRX）。

## 提案（待所有人决定，未改任何规则）

1. **暂不改止损，先并行记账。** 结算时为每条记录另算"3·ATR / 原距离 ×2 / 只到期"的结果，只记账不交易；到期结算约 150 条、入场日约 20 个后再决定。证伪条件保留。
2. **加与 LLM 可比的基线：** 对每条 LLM 入场同时记录同标的永远做多、20 日动量符号、趋势状态，以及多头占比和止损结构与 LLM 相同的随机方向。
3. **高成本资产设门槛：** 例如要求 |目标价 − 入场价| ≥ 3 倍往返成本，或给加密设更长的最短持有期；看板同时显示毛收益和净收益。
