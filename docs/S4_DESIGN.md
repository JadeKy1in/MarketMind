# S4 设计：仪表盘白箱 v1 + 内置汇报员

> 规格来源：`docs/SPEC_v3.md` §10、§13（S4 验收：所有人能查看账本和影子成绩）。日期：2026-09-28。

## 范围

- **做**：新的白箱首页（替换旧仪表盘，旧页面保留在 `/legacy`）；读统一账本、影子运行报告、决策简报；内置只读汇报员；修复成本面板字段。
- **不做**：晋升评审的计算（S7）；证据层数据（S5 接入后在同一页面显示）；实盘持仓（S6）；旧影子数据面板的迁移（旧 `/api/shadows/*` 留给清理阶段处理）。

## 页面（`/`，`marketmind/whitebox.html`）

| 区块 | 数据来源 | 说明 |
|---|---|---|
| 今日简报 | 最新一份 `.claude/briefs/<日期>.json` | 当天没有就显示最近一份，并标出日期 |
| 统一账本 | `data/ledger.db` | 按来源类型、来源、状态、标的筛选；点击任一记录看全部字段和当时的行情快照 |
| 影子竞技场 | 账本 + 名册 + 最新运行报告 | 每个影子：记录数、各状态数、已结算胜率、平均净收益、相对市场 / 领域基准超额、Brier、最小仓位占比；并列它的同领域随机基准成绩 |
| 证据层 | S5 | S5 之前显示"未接入" |
| 主管线推理链 | 最新简报 | L1 → L2 候选 → L3 明细 → 红队 → 决策原文 → 交易卡 / 不交易卡 |
| 晋升淘汰日志 | 名册 + 账本 | 所有影子目前都在"见习"阶段：显示已有记录的交易日数 / 60；评审在 S7 实现前一律标"未评审"；暂缓的影子列出原因 |
| 系统健康 | 账本、简报、运行报告、token 用量日志 | 最近一次运行、结算、影子交卷率、token 用量、数据源状态 |
| 汇报员 | 以上全部 | 见下 |

所有数字都来自文件或数据库，页面不做估算；缺数据时直接写"无数据"。

## 计分（`marketmind/ledger/scoreboard.py`）

- 按 `(source_type, source_id)` 分组。
- 胜率、平均净收益、超额、Brier 只用 `settled` 记录；没有已结算记录时为空，不是 0。
- 最小仓位占比 = 仓位 ≤ $100 的记录 / 全部记录（SPEC §6.1：超过 60% 降权，S7 使用）。
- 活跃交易日 = 有记录的不同日期数（UTC 日），用于"见习 x/60"。

## 汇报员（`marketmind/api/reporter.py`，`POST /api/reporter`）

- 只读：只把账本、简报、计分板的数据作为上下文交给 Flash；不写任何文件。
- 回答中提到的每条记录都要写记录编号（`[entry_id]`）；拿不到数据时直接说"数据不可用"。
- 代码核对：回答里出现的 16 位编号若不在账本中，附加警告；上下文过大时只放最近的记录并注明截断。
- 服务器启动时不初始化 LLM；第一次提问时按配置初始化。没有密钥时返回明确的错误信息。

## token 用量

- 每日运行结束后，把 `usage_tracker.snapshot()` 追加到 `data/token_usage.jsonl`（日期、模式、各阶段用量）。健康面板读取最近几条。
- 旧 `/api/cost` 读取的字段名在 `TokenBudget.report()` 中不存在，改为读取实际字段。

## 验收

- 离线测试覆盖：计分板、数据接口（用临时账本和临时文件）、汇报员（模拟 LLM，检验编号核对）。
- 本机启动服务器，页面各区块都能从真实的 `data/ledger.db` 显示数据（截图或接口输出为证）。
